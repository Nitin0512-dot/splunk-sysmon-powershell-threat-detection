# Splunk Sysmon Powershell Threat Detection

## Overview
This Project detect and investigate suspicious powershell activity

## Objectives
- Detect suspicious powershell execution
- Analyze powershell command-line activity
- Identify suspicious parameters such as 'EncodedCommand' , '-nop' , '-w hidden' , and execution policy bypass
- Investigate parent-child process relationships
- Analyze and correlate powershell network connections
- Identify potentials IOCs and map activity to MITRE ATT&CK
